# PriceCompare1

Комплексний десктопний застосунок для імпорту, каталогізації та порівняння прайс-листів різних постачальників. Графічний інтерфейс дозволяє керувати усіма діями без командного рядка: імпортувати файли, переглядати товари, шукати, порівнювати пропозиції та експортувати результати.

## Можливості

- Імпорт прайсів у форматах CSV та JSON з автоматичним вибором постачальника.
- Збереження прайсів у локальному сховищі та їх структурований перегляд.
- Автоматичне присвоєння тегів товарам на основі ключових слів або власних правил.
- Пошук по товарах із підтримкою як точних збігів, так і «розумного» (fuzzy) пошуку.
- Порівняння пропозицій по SKU чи за назвою товару та швидкий експорт результатів.
- Перелік найвигідніших пропозицій серед усіх постачальників.
- Експорт у CSV або JSON на кожному етапі роботи.

## Встановлення

Вимоги: Python 3.11+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # якщо потрібно, але проєкт працює на стандартній бібліотеці
```

## Запуск

```bash
python main.py
```

Після запуску відкриється головне вікно з вкладками:

- **Каталог постачальників** – імпорт прайсу, перегляд списку постачальників та їхніх товарів, експорт чи видалення даних.
- **Пошук** – пошук товарів по всіх або вибраних постачальниках, у тому числі нечіткий (fuzzy) пошук із налаштуванням порогу та ліміту результатів.
- **Порівняння** – порівняння пропозицій по SKU або за назвою товару з можливістю експорту отриманого списку.
- **Найкращі пропозиції** – добірка найвигідніших цін для кожного SKU серед усіх постачальників.

У будь-якій вкладці доступний експорт у CSV/JSON. Для імпорту використовуйте кнопки «Імпорт прайсу» та оберіть потрібний файл (`.csv` або `.json`). За потреби додатково вкажіть правила авто-тегування (див. нижче).

У репозиторії містяться приклади CSV-файлів `sample_supplier_a.csv` та `sample_supplier_b.csv`, які можна використати для швидкого тестування застосунку.

## Кастомні правила тегування

Створіть JSON-файл з описом правил:

```json
{
  "rules": [
    {"tag": "office", "keywords": ["chair", "desk", "table"]},
    {"tag": "gaming", "keywords": ["gaming", "rgb", "geforce"]}
  ]
}
```

Далі відкрийте застосунок та в меню **«Налаштування → Завантажити правила тегування»** виберіть створений JSON-файл. Нові імпорти будуть автоматично використовувати ці правила.

## Структура проєкту

- `price_compare/models.py` — основні моделі.
- `price_compare/io.py` — імпорт та експорт даних.
- `price_compare/tagging.py` — логіка авто-тегування.
- `price_compare/comparator.py` — інструменти порівняння.
- `price_compare/search.py` — пошук по товарах.
- `price_compare/repository.py` — сховище прайсів.
- `price_compare/gui.py` — графічний інтерфейс застосунку.

## Створення виконуваного файлу (.exe)

1. Встановіть [PyInstaller](https://pyinstaller.org/):

   ```bash
   pip install pyinstaller
   ```

2. Запустіть збірку у режимі одного файлу без консольного вікна:

   ```bash
   pyinstaller --onefile --noconsole main.py
   ```

3. Готовий виконуваний файл буде знаходитись у каталозі `dist/` і матиме назву `main.exe`. Запускайте його подвійним кліком – одразу відкриється графічний інтерфейс.

4. За необхідності додайте поруч із виконуваним файлом каталог із даними (за замовчуванням застосунок зберігає все у `.price_compare_data` в домашній директорії користувача).
