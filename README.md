# PriceCompare1

Комплексний десктопний застосунок для імпорту, каталогізації та порівняння прайс-листів різних постачальників. Графічний інтерфейс дозволяє керувати усіма діями без командного рядка: імпортувати файли, переглядати товари, шукати, порівнювати пропозиції та експортувати результати.

## Можливості

- Імпорт прайсів у форматах CSV, JSON, XML та Excel (`.xlsx`) з автоматичним вибором постачальника.
- Гнучке зіставлення колонок під час імпорту: можна задати власне відображення назв або скористатися вбудованими синонімами
  (наприклад, «артикул», «article», «код товару» → `sku`).
- Збереження прайсів у локальному сховищі та їх структурований перегляд.
- Автоматичне присвоєння тегів товарам на основі ключових слів або власних правил.
- Пошук по товарах із підтримкою як точних збігів, так і «розумного» (fuzzy) пошуку.
- Порівняння пропозицій по SKU чи за назвою товару та швидкий експорт результатів.
- Перелік найвигідніших пропозицій серед усіх постачальників.
- Експорт у CSV, JSON, XML або Excel на кожному етапі роботи.

## Встановлення

Вимоги: Python 3.11+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # якщо потрібно, але проєкт працює на стандартній бібліотеці
pip install pandas openpyxl gspread gspread_dataframe
```

## Запуск

```bash
python main.py
```

Після запуску відкриється головне вікно з вкладками:

- **Каталог постачальників** – імпорт прайсу, перегляд списку постачальників та їхніх товарів, експорт чи видалення даних.
- **Пошук** – пошук товарів по всіх або вибраних постачальниках, у тому числі нечіткий (fuzzy) пошук із налаштуванням порогу та ліміту результатів.
- **Порівняння** – порівняння пропозицій по SKU або за назвою товару з можливістю експорту отриманого списку.
- **Найкращі пропозиції** – добірка найвигідніших цін для кожного SKU серед усіх постачальників.

У будь-якій вкладці доступний експорт у CSV/JSON/XML/Excel. Для імпорту використовуйте кнопки «Імпорт прайсу» та оберіть потрібний файл (`.csv`, `.json`, `.xml` або `.xlsx`). За потреби додатково вкажіть правила авто-тегування (див. нижче).

У репозиторії містяться приклади CSV-файлів `sample_supplier_a.csv` та `sample_supplier_b.csv`, які можна використати для швидкого тестування застосунку.

## Налаштування експорту у Google Sheets та Prom

1. Вкажіть ідентифікатор Google Spreadsheet у `config.yaml` (секція `sheets.spreadsheet_id`).
2. Налаштуйте сервісний акаунт для Google API та збережіть JSON з ключами. Створіть змінну середовища `GOOGLE_APPLICATION_CREDENTIALS` із шляхом до цього файлу, або покладіть його у корінь проєкту під назвою `service_account.json` — `gspread` знайде його автоматично.
3. За потреби змініть директорію для готових файлів експорту (`exports.output_dir`). За замовчуванням файли зберігаються у `./exports`.

### Формування вкладок Export_Staging / Export_Prom

CLI-команда будує нормалізовані таблиці та оновлює два аркуші у Google Sheets:

```bash
python -m export_pipeline.cli export --channel prom --format csv
```

- У Spreadsheet автоматично з'являться (або оновляться) вкладки `Export_Staging` та `Export_Prom`.
- Значення записуються як plain-text без формул, тому Google-файли можна одразу передавати менеджерам або завантажувати як CSV.

Щоб перевірити роботу без підключення до Google, запустіть команду у середовищі без `gspread` — оновлення аркушів пропуститься з попереджувальним повідомленням, але локальні файли сформуються.

### Експорт у CSV/XLSX/XML

Команда `export` приймає один або кілька форматів:

```bash
python -m export_pipeline.cli export --channel prom --format csv xlsx xml
```

- CSV та XLSX зберігаються з іменем `prom_export_YYYYMMDD_HHMM.*`.
- XML для Price.ua отримує назву `priceua_YYYYMMDD_HHMM.xml` і містить не більше 10 тегів `<image>` на товар, коректно виставлені `available`, `in_stock`, `priceuah` та екрановані спецсимволи.
- Абсолютні шляхи до створених файлів друкуються у stdout.

Для швидкого тесту використовується файл `tests/data/sample_raw.csv`. Ви можете підмінити його власними даними або покласти `export_raw.csv` до директорії `data_root`, вказаної у конфігурації.

### Makefile

Передбачено спрощену перевірку експорту:

```bash
make test-export
```

Команда запускає XML-експорт для Prom та перевіряє появу файлу `exports/priceua_*.xml`.

## Налаштування зіставлення колонок

Імпортер автоматично намагається знайти основні стовпці (`sku`, `name`, `price`) за допомогою вбудованих синонімів.
Наприклад, заголовки «артикул», `article`, «код товару» будуть прив'язані до поля SKU, а «ціна» чи «вартість» — до price.
Якщо автоматичне визначення не знайшло всі обов'язкові поля, CLI запропонує вручну зіставити їх із доступних заголовків файлу.
За потреби можна передати власне зіставлення колонок:

- У CLI: `python -m price_compare import SUPPLIER data.csv --mapping '{"sku": ["артикул", "код товару"], "name": "назва позиції", "price": "вартість"}'`
- Або вказати шлях до JSON-файлу зі схемою, наприклад:

  ```json
  {
    "sku": ["art", "код"],
    "name": "найменування",
    "price": "ціна з ПДВ"
  }
  ```

  Виклик: `python -m price_compare import SUPPLIER data.xlsx --mapping mapping.json`

У програмному коді зіставлення можна передати напряму в `PriceListImporter.load(..., column_mapping=...)`,
а власні синоніми — через аргумент `column_aliases` конструктора імпортера.

## Кастомні правила тегування

Створіть JSON-файл з описом правил:

```json
{
  "rules": [
    {"tag": "office", "keywords": ["chair", "desk", "table"]},
    {"tag": "gaming", "keywords": ["gaming", "rgb", "geforce"]}
  ]
}
```

Далі відкрийте застосунок та в меню **«Налаштування → Завантажити правила тегування»** виберіть створений JSON-файл. Нові імпорти будуть автоматично використовувати ці правила.

## Структура проєкту

- `price_compare/models.py` — основні моделі.
- `price_compare/io.py` — імпорт та експорт даних.
- `price_compare/tagging.py` — логіка авто-тегування.
- `price_compare/comparator.py` — інструменти порівняння.
- `price_compare/search.py` — пошук по товарах.
- `price_compare/repository.py` — сховище прайсів.
- `price_compare/gui.py` — графічний інтерфейс застосунку.

## Створення виконуваного файлу (.exe)

1. Встановіть [PyInstaller](https://pyinstaller.org/):

   ```bash
   pip install pyinstaller
   ```

2. Запустіть збірку у режимі одного файлу без консольного вікна:

   ```bash
   pyinstaller --onefile --noconsole main.py
   ```

3. Готовий виконуваний файл буде знаходитись у каталозі `dist/` і матиме назву `main.exe`. Запускайте його подвійним кліком – одразу відкриється графічний інтерфейс.

4. За необхідності додайте поруч із виконуваним файлом каталог із даними (за замовчуванням застосунок зберігає все у `.price_compare_data` в домашній директорії користувача).
